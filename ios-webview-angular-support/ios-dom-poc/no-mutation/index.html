Node contract (no rule rewrites)

Synthetic nodes use the capture's own keys (label, value, text, traitsStringArray, rect, textProperties, voiceOverCaption, isHittable…). Type names hit the existing matchers: WebButton (…Button), WebImageView (…ImageView), WebLabel (…Label), WebSwitch, TextField / SearchField (WDA vocabulary already in inputTypeRoleIOS), WebTappableView (contains "Tappable"). Controls carry a boundary colour in nonTextColor; their text lives in a non-accessible caption child, like UIButtonLabel.

Rule-side changes (small, web-only arms)

  • matchers: add TextField, SearchField, WebTappableView…
  • unsupported-type: WebTappableView joins the allow-list (click listener, no role)
  • missing-view-type: WebTappableView must announce Button / Link
  • two-dimensional-scroll: WebScrollView with both axes
  • responsive-containers: WebContainer clipping its content

Per the cross-repo mirror rule these need the matching Ruby changes before shipping.

The one technique worth calling out

// Click handlers are invisible to an isolated world (page JS objects aren't shared). A PAGE-world user
// script at document start wraps addEventListener and leaves a DOM marker the extractor reads.
EventTarget.prototype.addEventListener = function (type, l, o) {
  if (TYPES.has(type) && this instanceof Element) this.setAttribute('data-bs-a11y-click', '1');
  return orig.call(this, type, l, o);
};

This marker (a data-bs-a11y-* attribute) is the only thing the layer writes into the page. It doesn't change layout or rendering.

5 · Production notes and risks

  • Scope: iOS 14+ (WKContentWorld). Main frame + same-process frames; closed shadow roots, canvas UIs and SFSafariViewController stay out of reach, and are reported as "not assessed".
  • Cost: 15 ms per scan at p50 (22 ms max) across 72 scans, and rule evaluation stays at ~4 ms.
  • Text magnification: reported as not applicable for web text. It isn't a pass, so the report must say "not assessed" for web text-scaling.
  • Side effects: the page-world hook wraps addEventListener and adds data-bs-a11y-* attributes. Nothing else in the page is touched.
  • Contracts: synthetic uids use the ObjectIdentifier(0x7eb…) shape; webSource: "dom" marks them for the server. The mirror-contract rule applies to the 4 rule arms.
  • Verification loop: keep the LCA / Web Inspector channel as an offline verifier of accessible names against WebCore (approach A).
