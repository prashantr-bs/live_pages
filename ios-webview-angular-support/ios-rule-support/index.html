iOS rules on WebView content: what the DOM-layer POC supports

The 37 rules whose supported_platform includes ios in app-accessibility rule_config.json. Measured on the Angular Rule Lab (iPad, iPadOS 26.5) with the read-only DOM layer v5 (ios_app_patcher branch webview-dom-poc). The stock production dylib detects 0 of these on WebView content: it sees no web elements. Detected = expected-FAIL test cases reported FAIL on device; +AI = sent to AI review with correct inputs (verdict pending). FP = expected-PASS test cases reported FAIL.
